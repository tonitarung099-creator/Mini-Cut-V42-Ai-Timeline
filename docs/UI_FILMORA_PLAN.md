# Filmora-like UI Plan

Goal: familiar interaction, not a visual clone.

## Main workspace

- Top bar: File/Edit/View, Import, Undo/Redo, Export.
- Left: Media/Project/Audio/Subtitles/AI assets.
- Center: video preview and transport controls.
- Right: Inspector/Properties for selected timeline item.
- Bottom: resizable multi-track timeline with ruler, playhead, snapping, zoom and track controls.
- AI Agent: dockable/compact panel showing current V42 unit, action plan, progress, checkpoint and review controls.

## First milestone

Before AI automation, manual editing must support clip insertion, move, trim, split, delete, snapping, zoom, multi-track video/audio and subtitle tracks. AI will later call the same underlying commands.
